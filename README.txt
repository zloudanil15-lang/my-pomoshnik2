Умный помощник для Тилека — файлы проекта

Для быстрой проверки:
1. Откройте index.html в браузере.
2. Приложение работает как веб-приложение и сохраняет данные в хранилище браузера на этом устройстве.

Для установки как отдельного приложения на Android:
- Сначала разместите эти файлы на HTTPS-хостинге, затем откройте сайт в Chrome и выберите «Установить приложение» / «Добавить на главный экран» (вариант зависит от браузера).
- Этот ZIP пока не является APK. Для получения APK потребуется отдельная сборка и проверка на Android.
